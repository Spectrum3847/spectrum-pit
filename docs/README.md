# Spectrum Pit documentation

This is the documentation the public mirror carries. The team's internal
manuals (release process, CI workflow reference, database plan, and the rest)
live in the private repository and are not published here, so the app built
from this mirror bundles this page and nothing else under `docs/`.

## What the app does

Spectrum Pit is one Flutter app covering pit logistics at an FRC event:

- **Inventory**: every tool and part, where it lives in the lab or the pit,
  with a map of both.
- **Event packing**: the four-stage packing workflow (Packing, Staging,
  Loading, Ready), with one optional photo per item.
- **Borrowed tools**: what left the pit with whom, and what came back.

It runs on iOS, Android, and desktop (Windows, macOS, Linux). Install
instructions for each are in [README.md](../README.md).

## Building it yourself

The toolchain is Flutter 3.47.2 / Dart 3.13.2. From a checkout:

```bash
flutter pub get
flutter run
```

The gates CI runs, and the ones a pull request has to pass, are listed in
[CONTRIBUTING.md](../CONTRIBUTING.md).

## Reporting something

Open an issue on this repository. Bugs, install problems, and questions about
the app are all welcome here. Changes to `README.md`, `CONTRIBUTING.md`,
`LICENSE`, and `.github/` are generated by the release sync and have to be
made privately, so those go through an issue rather than a pull request.
